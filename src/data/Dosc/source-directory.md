## การตรวจแหล่ง

แหล่งเดิมนำมาจาก dosc1.md และข้อมูล repo; เป็น seed สำหรับค้น ไม่ได้ตรวจทุกกิจกรรมใหม่ในรอบนี้ เว็บไซต์มหาวิทยาลัยที่เพิ่มและตรวจพบหน้าเจ้าของสถาบันวันที่ 3 ต.ค. 2026:

- บูรพา: https://www.buu.ac.th/
- วลัยลักษณ์: https://www.wu.ac.th/th
- พะเยา: https://www.up.ac.th/

การพบ homepage ยืนยันชื่อโดเมนเท่านั้น ไม่ยืนยันค่าย การแข่งขัน วันเปิดรับ หรือคุณสมบัติ ต้องค้นหน้าประกาศแยก

## Social และหน้าสมัคร

บัญชีใน dosc1.md อาจเปลี่ยนชื่อ ย้ายบัญชี หรือถูกทำเลียนแบบ ตรวจ cross-link จากหน้าเจ้าของกิจกรรมก่อนอ้างว่า official. ลิงก์ short URL ต้องเปิดปลายทางได้ก่อนใช้ยืนยันรายละเอียด. Facebook/Instagram snippet หรือโพสต์ปีเก่าใช้ค้นชื่อเท่านั้น อย่าเดาข้อความในโปสเตอร์ที่อ่านไม่ได้.

## ขยายพื้นที่ค้น

จาก registry ให้ค้นภาควิชา สโมสรนักศึกษา ศูนย์นวัตกรรม วิทยาเขต และหน่วยประชาสัมพันธ์ แยกการรับเข้าศึกษาระดับปริญญาจากกิจกรรมมัธยม ขยายมหาวิทยาลัยนอก registry ด้วยคำค้น site:ac.th โดยตรวจชื่อสถาบันก่อนเพิ่ม ห้ามสร้าง hostname คณะขึ้นเอง
