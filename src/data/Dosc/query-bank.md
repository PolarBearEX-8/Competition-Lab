# Query bank

แทน DOMAIN / UNIVERSITY / EVENT / YEAR / BEYEAR ด้วยแหล่งและปีจริง ใช้ปีถัดไปเพื่อค้นประกาศล่วงหน้าได้ แต่ห้ามสร้างงานปีถัดไปเอง คำค้นด้านล่างเป็น template ไม่ใช่รายชื่อกิจกรรมที่มีจริง

## กติกาคำค้น

- สลับชื่อไทย อังกฤษ และตัวย่อของมหาวิทยาลัย; query หนึ่งให้สั้นพอค้นได้
- ขยายจากชื่อกิจกรรมในผลค้นไปหา ประกาศเปิดรับ กติกา วันปิด และประกาศเปลี่ยนกำหนด
- อย่าใช้ทุกคำหรือทุกสาขาใน query เดียว และอย่าบังคับปีในทุก query เพราะบางประกาศไม่ใส่ปีในชื่อ
- การค้นชื่อรุ่นต้องใช้รุ่นที่พบในประกาศจริง
