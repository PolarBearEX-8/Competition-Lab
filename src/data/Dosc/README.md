## การอ่านของสคริปต์

Planner อ่านชุดคำค้น `query-bank.md`, `coverage-plan.md` และแหล่งใน `sources.json` ที่เลือกตามวัน พร้อมชุดคำค้นเดิมใน Tools ส่วนขั้นวิเคราะห์อ่าน `verification.md` กับ `evidence-examples.md` เพิ่มจาก prompt เดิม ไฟล์ประวัติไม่ได้ส่งเข้า AI ทุกครั้ง เพื่อไม่ให้กำหนดการเก่าปะปนกับหลักฐานปัจจุบัน

แหล่งใน registry เป็นเป้าหมายค้น ไม่ใช่ whitelist รับรองความถูกต้อง ไม่ใช่หลักฐานว่ากิจกรรมเปิดรับ และไม่ใช่การยืนยันว่าทุกหน้าเปิดอ่านได้ ทุกข้อมูลที่เผยแพร่ต้องมาจากผลค้นรอบจริง เก็บ URL ของประกาศแทน homepage เมื่อหาได้
